# Date de exemplu

`exemplu-serii.csv` are trei serii **sintetice**, generate cu un script, nu măsurate: ele nu descriu nicio regiune reală și nu se citează în rapoarte. Folosesc doar ca notebook-ul `analiza-sablon.ipynb` să ruleze înainte ca echipa să-și pună datele în depozit; are intenționat trei valori lipsă, pentru pasul de curățare.

| Coloană | Tip | Semnificație |
| --- | --- | --- |
| `an` | întreg | anul |
| `regiune` | text | numele seriei: Regiunea A, B sau C |
| `valoare` | real, cu punct zecimal | valoarea unui indicator imaginar |
